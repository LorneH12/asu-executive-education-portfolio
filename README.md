# ASU Executive Education Portfolio

Standalone GitHub Pages portfolio for Lorne Hopkins. The site is intentionally separate from Lorne's other portfolio repositories.

## Edit the site

- `index.html` contains all visible copy and links.
- `css/styles.css` contains layout, colors and responsive rules.
- `js/main.js` controls the mobile menu, header state and entrance effects.
- `assets/` contains the portrait and downloadable résumé.

GitHub Actions publishes the repository root to GitHub Pages after every push to `main`.
